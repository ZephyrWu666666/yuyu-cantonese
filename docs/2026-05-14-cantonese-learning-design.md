# 语于 — 粤语学习网站设计文档

## 概述

「语于」是一款针对喜欢陈奕迅粤语歌的普通话使用者的粤语学习网站。用户通过两种模式（歌词逐句拆解 / 词汇提取学习）在陈奕迅的歌曲中逐步学会粤语，每个粤语词汇和句子都配有温和的粤语女声发音。

## 目标用户

- 普话使用者，喜欢陈奕迅粤语歌
- 想通过歌曲学粤语，而非传统课本方式

## 核心功能

### 两种学习模式

**模式 A — 歌词逐句拆解**：
- 歌词逐行展示：粤语原文 + 粤拼 + 普通话翻译
- 点击任意一行播放该句粤语发音
- 跟唱模式：点击「跟唱」按钮进入，逐句自动播放发音并高亮，用户跟读，再点击退出
- 底部进度条显示当前播放位置

**模式 B — 词汇提取学习**：
- 从当前歌曲提取粤语特色词汇（人工标注，选取与普通话差异大、发音或用法不同的词）
- 卡片式展示：正面粤语+粤拼，点击翻转显示普通话意思+发音
- 词汇可标记"已掌握"，下次跳过
- 学完词汇后可跳转回模式 A 在歌词中巩固

**模式切换**：顶部切换按钮，随时可切，两个模式共享同一首歌数据。

### 音频配音

- TTS 服务：Azure Speech Service
- 语音：`zh-HK-HiuMaanNeural`（粤语女声，温柔声线）
- 词汇音频：每个粤语词汇单独生成 mp3，文件名为拼音（如 `pin1.mp3`）
- 句子音频：每句歌词单独生成，文件名为歌曲 id + 行号（如 `fushishanxia_03.mp3`）
- 后期计划：补充真人粤语母语者录音

### 数据模型

```typescript
interface Song {
  id: string;                    // e.g. "富士山下"
  title: string;                 // 歌名
  album: string;                 // 专辑
  year: number;                  // 发行年份
  lyrics: LyricLine[];          // 歌词逐行
}

interface LyricLine {
  cantonese: string;             // 粤语原文 "拦路雨偏似雪花"
  pinyin: string;                // 粤拼 "laan4 lou6 jyu5 pin1 ci5 syut3 faa1"
  mandarin: string;              // 普通话翻译 "拦路的雨偏偏像雪花"
  words: Word[];                 // 该行包含的粤语词汇
}

interface Word {
  cantonese: string;             // "偏"
  pinyin: string;                // "pin1"
  mandarin: string;              // "偏偏"
  audioPath: string;             // "/audio/words/pin1.mp3"
}
```

### 数据流

1. **构建时**：脚本从翡翠粤语歌词抓取歌词 → 解析为结构化 JSON → Azure TTS 生成音频
2. **运行时**：静态页面加载 → 用户选歌 → 切换模式 → 点击播放音频

## UI 设计

### 整体风格

深色背景，沉浸式音乐播放器风格（类似 Spotify/Apple Music）。

### 首页

- 顶部：网站标题「语于」+ 简短描述
- 主体：歌曲网格，每首歌一张卡片，显示歌名、专辑、年份
- 搜索/筛选：按歌名搜索，按专辑/年份筛选
- 背景：深灰/黑色渐变

### 歌曲页

- 左侧/顶部：歌曲信息（歌名、专辑、年份）
- 中央：歌词区域（模式 A）或词汇卡片（模式 B）
- 顶部切换栏：「逐句学习」/「词汇学习」两个 tab
- 底部：音频控制条（播放/暂停、进度、音量）

### 配色

- 背景：`#0a0a0a` ~ `#1a1a2e` 深色渐变
- 主色：`#4ade80`（森林绿，符合用户偏好）
- 文字：`#e5e5e5` 浅灰
- 强调：`#f59e0b` 金色（用于高亮当前句/词汇）

### 交互细节

- 点击句子/词汇时有微动画（scale + 阴影）
- 当前播放的句子高亮，自动滚动到可视区域
- 词汇卡片翻转动画用 CSS transition

## 开发阶段

### Phase 1 — 数据与基础

- 从翡翠粤语歌词抓取 40 首歌歌词
- 设计数据结构，生成 songs.json
- 搭建 Next.js 项目骨架

### Phase 2 — 核心功能

- 歌曲列表首页
- 模式 A：歌词逐句展示 + 发音播放
- 模式 B：词汇提取 + 卡片学习
- Azure TTS 音频生成脚本

### Phase 3 — 打磨

- UI 精细化，动画效果
- 搜索筛选功能
- 本地进度存储（localStorage）

## 预估规模

- 40 首歌 × 平均 30 句 ≈ 1200 个句子音频
- 去重词汇约 800-1200 个
- 总计约 2000 个音频文件，约 50-80MB
